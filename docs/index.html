FREQUENTLY ASKED QUESTIONS

Got Questions? We’ve Got Answers.

Is RiftOps safe from Vanguard and Riot bans?

Yes, 100%. RiftOps complies with Riot Games’ third-party developer policies. It never reads or modifies the memory of League of Legends.exe, does not inject DLLs, and contains no overlay hooks. It communicates exclusively through the official, supported League Client API (LCU) and Game Client Data API provided by Riot on your local machine.

How does the Presence Shield (Appear Offline) work?

RiftOps establishes a secure local loopback chat proxy between your League Client and Riot’s XMPP chat server. When you toggle Offline, RiftOps intercepts chat presence stanzas while keeping game matchmaking intact, allowing you to play without appearing online to friends.

Are my account credentials or passwords stored?

Never in plaintext. Account sessions are encrypted using your operating system's native hardware-backed encryption: Windows DPAPI on Windows and the macOS Keychain on macOS. RiftOps contains zero cloud servers, zero telemetry, and never transmits your login tokens anywhere.

How does the Phone Companion connect to my PC?

The companion communicates directly over your local home Wi-Fi network (P2P LAN). No traffic ever goes to the cloud or an external server. The QR code contains a cryptographically random single-use token that expires in 5 minutes for airtight local security.
