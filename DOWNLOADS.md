# RiftOps downloads

RiftOps is distributed through the [GitHub Releases](https://github.com/HassanSalah120/RiftOps/releases) page.

## Windows

Download the latest `RiftOps-<version>-win-x64.exe` and its matching `.sha256`
file. While the SignPath Foundation application is pending, Windows releases
are built and published unsigned. They may show an **Unknown publisher** or
SmartScreen warning. Once SignPath is approved and enabled, release notes will
identify the Authenticode-signed builds and their SignPath publisher.

Verify the checksum before running a release and download only from the
official GitHub repository. Do not disable antivirus protection to run a
release.

## macOS

Download `RiftOps-macOS.zip` and its matching `.sha256` file. Check the release
notes for the signing and notarization status of each macOS build.

## Source

The complete source code, build scripts, tests, and release workflows are
available at the [RiftOps repository](https://github.com/HassanSalah120/RiftOps).
